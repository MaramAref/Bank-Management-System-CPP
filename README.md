# Bank Management System

A console-based Bank Management System developed using C++. The project provides basic client management operations and banking transactions, with data stored in a text file.

## Features

### Client Management
- Display all clients.
- Add new clients.
- Delete existing clients.
- Update client information.
- Search for clients by account number.

### Banking Transactions
- Deposit money.
- Withdraw money.
- Display clients' balances.
- Calculate total balances.

## Technologies & Concepts
- C++
- Structures (`struct`)
- Vectors (`vector`)
- Functions and Enumerations (`enum`)
- References
- File Handling (`fstream`)
- Header Files
- Modular Programming

## Project Structure

- `Bank System.cpp`: Main program entry point and menu navigation.
- `Library.h`: Contains the project's functions and supporting logic.
- `Clients.txt`: Stores client records.

## How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE such as Visual Studio.
3. Make sure `Clients.txt` is available in the program's working directory.
4. Build and run the project.

## Data Storage

Client records are stored in `Clients.txt` using file handling techniques.

The program loads client data into memory and saves changes back to the file.

## Purpose

This project was developed to practice and apply fundamental C++ programming concepts, including data structures, functions, file handling, and modular code organization.
